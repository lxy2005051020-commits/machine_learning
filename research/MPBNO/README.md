# MPBNO · 有机小分子熔点预测新架构研究

**MPBNO**：Molecular Phase-Boundary Neural Operator  
**OPBL**：Ordinal Phase-Boundary Learning

本目录用于存放“仅依赖 SMILES + 实验熔点”条件下的深度学习模型创新研究。研究重点是**潜在分子间组装建模 + 单调温度阈值学习**，而非在现有回归模型上单纯拼接更多特征，也不依赖自由能、焓、熵或真实晶体结构标签。

## 核心研究框架

~~~mermaid
flowchart LR
    A["SMILES / 2D 图"] --> B["软交互位点"]
    B --> C["潜在组装接触核"]
    C --> D["谱协同特征"]
    D --> E["单调阈值分布"]
    E --> F["条件中位数熔点"]
~~~

核心条件函数为：

$$
S_\theta(T\mid G)=\Pr_\theta(Y>T\mid G).
$$

熔点点预测使用：

$$
\hat T_m=\inf\{T:S_\theta(T\mid G)\le 0.5\}.
$$

## 研究状态

- **已完成：** 概念架构、数学参数化、训练与评估设计。
- **未完成：** 算子实现、实验验证、超参数搜索和发表级新颖性核验。
- **项目对照目标：** 此前报告的 scaffold-split MAE 为 22.522 K；只有在相同数据清洗与划分条件下才能严谨比较。
